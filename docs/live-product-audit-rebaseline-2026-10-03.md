Tenant/security: no additional authorization or secret path; trusted server persistence remains workspace scoped; no cross-tenant evidence. Recommended scope: explicitly document retained fields, preserve/recover source context, and define conservative uncertainty/abstention semantics before considering richer schema. Tenant/security: operational timeout precondition; graph/MCP server authority unchanged; no production exploit or live occurrence established.
